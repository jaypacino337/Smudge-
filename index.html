Step 2 — the layering system

How 125 drawings become 1,111 dogs

Generative NFT art is one idea repeated: every trait is a transparent PNG on an identical canvas, and the generator stacks them in a fixed order. Get the alignment right and the rest is bookkeeping.

Draw order

The one rule that matters

Every layer is drawn on the same 2048×2048 transparent canvas, with the subject at the same pixel anchors. If a hat sits 40px left of another hat, you'll be hand-fixing 1,111 images. 

# fixed anchors — every prompt cites these
body center X   1024
head top Y      560
eye line Y      880
muzzle Y        1120
shoulder Y      1500
held item       470, 1560

Generate the plain base body first, turn it into art/anchor-sheet.png, then attach that image to every other prompt with "match this reference exactly, output only the new element on transparent background." Skipping this step is the #1 reason collections come out misaligned.

Rarity is just a number in the filename

generator/layers/07-headwear/
backwards-cap#80.png   common
bucket-hat#45.png      uncommon
cowboy#25.png          rare
halo#6.png             epic
crown#5.png            legendary
none#180.png           no hat

Retune rarity by renaming files. No code changes. Exact counts for headline traits (3 laser eyes, 11 crowns) are pinned in config.forced.

Exclusion rules — the part everyone forgets

Some combinations are physically broken. The generator rejects and rerolls them. Write a rule the moment a preview makes you go "that looks wrong." 

// a cowboy hat crushes upright ears
{ when: ['fur:shiba-pricked'], forbid: ['headwear:cowboy'] }

// sunglasses over closed eyes reads as a bug, not a trait
{ when: ['eyes:sleepy'], forbid: ['eyewear:*'] }

// the cone of shame owns the entire neck
{ when: ['headwear:cone-of-shame'], forbid: ['outfit:*', 'eyewear:*'] }

// dark dog on a dark background = invisible at avatar size
{ when: ['background:void'], forbid: ['fur:black-lab'] }

The one number that matters. Pre-minting all 1,111 yourself costs ~3.2 SOL (~$242) on Metaplex Core — or ~24 SOL (~$1,834) on the legacy Token Metadata standard, which is the default a lot of guides still hand you. A Candy Machine moves that cost to the buyer and takes your side to about two dollars. Images are also shipped as 256-colour indexed PNGs: 182 MB down to 64 MB, at a mean per-channel error of 0.02/255 — you cannot see the difference on flat cel art, and upload size is what you pay for.

Priced August 2026 at SOL ≈ $75 and Arweave ≈ $20/GB. Both move — re-check before spending.

Questions

FAQ

Why 1,111?

Small enough that the floor means something, big enough for a real community, and it's the number the category has settled on. Change it in one place — generator/config.js → supply.

Why is the art drawn in code instead of by an image model?

Alignment. Every hat lands on the same skull because it's the same arithmetic. Prompted layers drift on position and scale even with a reference image attached, and you end up hand-nudging 15–20% of them — normally the single biggest time sink in a generative launch. Here that number is zero.

It also means the whole set redraws in about 20 seconds. Change a colour, a shape, or the entire style and re-run — iterating on 125 prompted images would take days per pass.

What's the catch with procedural art?

It's geometry, so it can't do texture, incidental detail, or the small imperfections a human illustrator brings. Next to hand-drawn work these read as simpler — a real illustrator would beat this.

That's a drop-in upgrade if the collection takes off: have someone redraw the 125 layers against the same anchors and filenames. The generator doesn't care where the PNGs came from, and the prompt packs in the Lab are still there if you'd rather go the image-model route now.

Do I need the token and the NFT to launch together?

No, and you probably shouldn't. Launching both at once splits attention and liquidity. Pick whichever you can execute well, get traction, then launch the other into an audience that already exists.

Are royalties enforced on Solana?

Only if you mint as pNFTs (programmable NFTs). Standard NFTs treat seller_fee_basis_points as a suggestion that marketplaces may ignore. Decide before you upload — it's not something you change afterwards.

Why does the build warn about my wallet?

config.creators ships with a placeholder address. Every metadata file carries it, so uploading without replacing it would point royalties at nothing. The build prints a warning at the end until you fix it.
