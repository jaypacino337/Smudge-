Draw order

The one rule that matters

Every layer is drawn on the same 2048×2048 transparent canvas, with the subject at the same pixel anchors. If a hat sits 40px left of another hat, you'll be hand-fixing 1,111 images. 

# fixed anchors — every prompt cites these
body center X   1024
head top Y      560
eye line Y      880
muzzle Y        1120
shoulder Y      1500
held item       470, 1560

Generate the plain base body first, turn it into art/anchor-sheet.png, then attach that image to every other prompt with "match this reference exactly, output only the new element on transparent background." Skipping this step is the #1 reason collections come out misaligned.

Rarity is just a number in the filename

generator/layers/07-headwear/
backwards-cap#80.png   common
bucket-hat#45.png      uncommon
cowboy#25.png          rare
halo#6.png             epic
crown#5.png            legendary

Retune rarity by renaming files. No code changes. Exact counts for headline traits (3 laser eyes, 11 crowns) are pinned in config.forced.

Exclusion rules — the part everyone forgets

Some combinations are physically broken. The generator rejects and rerolls them. Write a rule the moment a preview makes you go "that looks wrong." 

// a cowboy hat crushes upright ears
{ when: ['fur:shiba-pricked'], forbid: ['headwear:cowboy'] }

// sunglasses over closed eyes reads as a bug, not a trait
{ when: ['eyes:sleepy'], forbid: ['eyewear:*'] }

// the cone of shame owns the entire neck
{ when: ['headwear:cone-of-shame'], forbid: ['outfit:*', 'eyewear:*'] }

// dark dog on a dark background = invisible at avatar size
{ when: ['background:void'], forbid: ['fur:black-lab'] }

Step 3 — mass-produce it

From zero to minted

Ten steps. The generator already runs end-to-end on placeholder art, so you can test rarity, exclusions and metadata today, before a single real drawing exists.

Pick a concept

Paste its style block into art/prompts/00-style.md. That block gets prepended to all 125 prompts.

Generate the base body first

One plain dog, no traits, blank face. Build art/anchor-sheet.png from it — this is your alignment reference for everything else.

Run the prompt packs

Eleven batches in the Prompt Lab. Copy a whole category at once, paste into ChatGPT, attach the anchor sheet.

Drop PNGs into the layer folders

generator/layers/07-headwear/crown#5.png — the #5 is the rarity weight.

Fill in the None layers

npm run make-none writes a real transparent PNG for every optional category. A missing file silently breaks your rarity.

Preview and fix

npm run preview -- 60 gives you a contact sheet. Anything ugly becomes an exclusion rule. Repeat until clean.

Build the collection

npm run build -- 1111 → images, Metaplex metadata, and a rarity report. Deterministic: same seed, same collection, every time.

Devnet first

sugar launch against devnet. Mint five to yourself. Confirm they actually render on a marketplace before you spend real SOL.

Mainnet

Same command, mainnet RPC. Set your wallet in generator/config.js → creators first — the build warns you if you forget.

Token

Launch $BAWG separately. Same brand, same Discord, no promises you can't keep.

Questions

FAQ

Why 1,111?

Small enough that the floor means something, big enough for a real community, and it's the number the category has settled on. Change it in one place — generator/config.js → supply.

Can ChatGPT really make all 125 layers?

It can make all 125 drafts. Expect to hand-nudge 15–20% of them for alignment — image models drift on position and scale even with a reference attached. That's an afternoon in any editor that can move a PNG, not a lost week.

The two things that cut rework the most: attach the anchor sheet to every prompt, and generate one category per conversation so the model keeps the style in context.

What if the layers don't line up?

Generate the trait on top of the base body instead of alone, then mask the body out afterwards. Slower per layer, but alignment is perfect by construction because the model can see exactly where the head is.

Do I need the token and the NFT to launch together?

No, and you probably shouldn't. Launching both at once splits attention and liquidity. Pick whichever you can execute well, get traction, then launch the other into an audience that already exists.

Are royalties enforced on Solana?

Only if you mint as pNFTs (programmable NFTs). Standard NFTs treat seller_fee_basis_points as a suggestion that marketplaces may ignore. Decide before you upload — it's not something you change afterwards.

Why does the build warn about my wallet?

config.creators ships with a placeholder address. Every metadata file carries it, so uploading without replacing it would point royalties at nothing. The build prints a warning at the end until you fix it.
